§3 Phased implementation

Phase 1 — Test 09 Darwin branch

  • Add case "$(uname -s)" in Darwin) … esac block that:
    • Spawns 2 sessions via tmx new -s isol1 -d + tmx new -s isol2 -d
    • Reads back ulimit -t (CPU) + ulimit -u (NPROC) inside each session via send-keys/capture-pane
    • Asserts both values match the wrapper's defaults (86400s, 2666 procs derived from host)
    • SIGKILL session-1's tmux server directly; verify session-2's server survives with original PID
    • Captured evidence: ulimit readback per session + ps before/after kill

Phase 2 — Test 13 Darwin branch

  • Spawn a session, then a child shell with low RLIMIT_NPROC (e.g., 64)
  • Fork until limit hit; assert fork() returns EAGAIN
  • Captured evidence: actual fork count = NPROC - already-running pids (positive evidence per §11.4.5)

Phase 3 — Test 14 Darwin branch

  • 3 sessions A/B/C via tmx new
  • Capture each server's PID (tmx-LABEL socket)
  • Direct kill server A (SIGKILL)
  • Assert B + C servers still running with ORIGINAL PIDs
  • Assert tmx ls no longer shows A

Phase 4 — NEW Test 24 (Darwin CPU-cap enforcement, macOS-only)

  • Spawn a session with TMX_CPU_HARD_SEC=5
  • Inside the session, run a CPU-bound loop
  • Assert process is SIGXCPU'd ≤ 7 seconds (5s soft + epsilon)
  • Captured evidence: process exit signal + wall-clock duration
  • §11.4.3 dispatch: SKIPs on Linux (test 12 covers Linux memory pressure; Linux CPU cap is via cgroup)

Phase 5 — Retire M7-M10; add M20 + M21 Darwin rlimit mutations

§4 Anti-bluff invariants (verbatim user mandate, 2026-05-21)

"all existing tests and Challenges do work in anti-bluff manner — they MUST confirm that all tested codebase really works as expected! We had been in position that all tests do execute with success and all Challenges as well, but in reality the most of the features does not work and can't be used!"

Every Darwin branch added in this cycle MUST:

  1. Read CONTENT (ulimit values, ps output, fork return codes), not file existence.
  2. Use the operator path (tmx new -s NAME -d) per §102.
  3. SKIP-with-reason where macOS genuinely can't (kernel gap), citing the exact rlimit + reproducer per §11.4.6 no-guessing.
  4. Have a paired §103 layer-4 mutation in the meta-test.
