### Zero-escape meta-test (first ever)

`scripts/tests/meta_test_false_positive_proof.sh` reports **44 CAUGHT / 0 ESCAPED / 9 SKIPPED** on Mistborn this cycle. The pre-existing P5-M20 + P5-M21 escapes from v1.0.9 are now closed by tests 49 + 50:

- **Test 49** (`49_tmx_shell_init_guard_specific.sh`) asserts the
  distinctive `non-TTY guard fired` marker (TMX_INIT_DEBUG-gated
  stderr line) emits ONLY when the guard's body executes. Stripping
  the marker line via P5-M20 mutation → test FAILs even on Darwin
  (where libc previously masked the bug).
- **Test 50** (`50_cwd_hook_autoinstall.sh`) reads the LIVE server's
  hooks via `tmux show-hooks -g` after operator-path session spawn —
  NOT by manual `tmux run-shell 'set-hook …'` injection (which the
  pre-existing test 27 used and is why P5-M21 previously ESCAPED).
  Stripping the set-hook block via P5-M21 mutation → show-hooks
  empty → test FAILs.

ONLY on the golden testdata corpus. v1.0.16 introduces:

v1.0.15 introduced the DB with 48 validate findings (legacy items
defaulted to Type=Task; closure word "Fixed (→ Fixed.md)" expects
Type=Bug). v1.0.16 closes ALL findings:
