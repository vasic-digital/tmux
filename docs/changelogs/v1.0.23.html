vasic-digital tmux — v1.0.23 Release Notes

Revision: 1 Last modified: 2026-06-16T13:30:00Z Version: 1.0.23 / versionCode 24 Released: 2026-06-16 Hosts validated: Mistborn (Darwin arm64) + nezha (ALT Linux 6.12 x86_64)

Summary

v1.0.23 eliminates the cross-distro /lib64/libtinfo.so.6: no version information available warning that the containerized Linux build emitted on every tmux invocation when run on a host (ALT Linux on nezha) whose libtinfo lacks the build container’s NCURSES version nodes. terminfo is now linked statically so the warning is structurally impossible on any distribution, while glibc / jemalloc / libevent stay dynamic (the LD_PRELOAD-jemalloc architecture is preserved). The release also fixes three test-harness timing races (§11.4.1) surfaced while re-validating the full suite on real Linux hardware, and was validated green on both supported OSes.

Fixed

libtinfo cross-distro symbol-version warning (§11.4.81)

docker/build_inside_container.sh passes LIBTINFO_LIBS="-l:libtinfo.a" to ./configure. The Linux ELF then carries no libtinfo.so DT_NEEDED entry and 0 NCURSES6_TINFO versioned refs.

Before:

tmux/build/bin/tmux: /lib64/libtinfo.so.6: no version information available (required by tmux)

After:

$ tmux/build/bin/tmux -V    # stderr
tmux 3.6a                   # 0 warning lines; ldd shows no libtinfo.so

Partial-static (terminfo only) — ldd still lists libjemalloc.so.2, so the build-time jemalloc linkage and the wrapper’s LD_PRELOAD jemalloc are intact. NOT --enable-static (which yields a fully-static binary that drops jemalloc). Static terminfo still reads the host /usr/share/terminfo at runtime.

Test 27 — tmx-state cwd persistence (deterministic macOS FAIL)

Phase 3 recorded #{pane_current_path} after a blind sleep 0.4; macOS tmux updates the pane cwd ~1.5 s after send-keys "cd …" (measured), so it captured the stale path. Now polls until the cd is reflected before recording. PASS 3/3 on macOS and Linux.

Tests 12 & 14 — cgroup OOM tests (flaky false-negative)

The kernel OOM-kill is asynchronous and journalctl -k (the dmesg_restrict=1 fallback) ingests it with lag; a fixed-sleep single sample raced it. Now polls the kernel ring for the OOM line up to a generous timeout. PASS 5/5 with real OOM evidence; assertions unchanged.

Tests — added / hardened

  • scripts/tests/61_no_libtinfo_version_warning.sh — cross-platform regression guard (no loader warning; Linux: static-tinfo + jemalloc-preserved checks).
  • scripts/verify.sh CM-NO-DYNAMIC-LIBTINFO — layer-1 pre-build gate; refuses a Linux binary that dynamically links libtinfo.so (teeth: distro /usr/bin/tmux trips it).
  • Tests 27 / 12 / 14 hardened to poll real conditions (§11.4.1 / §11.4.50).
