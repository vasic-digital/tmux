**Scope:** v1.0.11 operator-facing uninstall entry point per §11.4.18

## Purpose

Operator-facing thin wrapper that delegates to `scripts/setup.sh --uninstall`.
Single source of truth for what "uninstall" means lives in
`setup.sh`'s `_do_uninstall` function; `uninstall.sh` only exists so
operators have a discoverable verb (`bash scripts/uninstall.sh`) that
mirrors `bash scripts/setup.sh`.

## Usage

```bash
# Standard uninstall — preserves operator data under ~/.tmx/
bash scripts/uninstall.sh

# Also remove per-session last-pwd state in ~/.tmx/
bash scripts/uninstall.sh --purge-state
```

## Inputs

| Source | Meaning |
|---|---|
| `--purge-state` flag | When set, also remove `~/.tmx/` (per-session last-pwd state). Default: preserve. |
| `--help` / `-h` | Show this guide's header. |
| `PURGE_STATE=1` env var | Same effect as `--purge-state` (used by tests). |

## Outputs

Side-effecting only. No stdout JSON / structured output. Per-step
progress lines printed to stderr by the underlying
`_do_uninstall` function.

## What is removed

| Artefact | Removed? | Why |
|---|---|---|
| `─── vasic-digital optimized tmux ───` fenced block in `~/.bashrc` + `~/.zshrc` | YES | Generated by setup.sh; nothing else should reference it. |
| Legacy pre-v1.0.9 unfenced `if command -v tmx ...; then ...; fi` snippet | YES | Pre-v1.0.9 hand-pasted snippets that would otherwise double-trigger. |
| `~/.tmux.conf` (only if it contains `vasic-digital optimized tmux configuration`) | YES | Setup.sh generated; operator's pre-existing file preserved via backup `~/.tmux.conf.pre-vasic-digital`. |
| `scripts/tmx` (wrapper) | YES | Generated from `scripts/tmx.template` at install time. |
| `scripts/tmx-shell-init.sh` (shell init — v1.0.9+) | YES | Generated from `scripts/tmx-shell-init.sh.template` at install time. |
| `scripts/tmx-state-bin` (Go binary — v1.0.9+) | YES | Built from `scripts/tmx-state/` Go source at install time. |
| `~/.tmx/state.json` (per-session last-pwd) | NO (unless `--purge-state`) | §9 zero-risk-data-safety — operator data. |
| `tmux/build*/` (compiled tmux binary) | NO | Rebuild costs minutes; manual `rm -rf tmux/build*` if desired. |

## Side-effects

- Touches the operator's `~/.bashrc`, `~/.zshrc`, `~/.tmux.conf` (only
  to remove our content).
- Removes generated files inside the project's `scripts/` directory.

## Dependencies

- `scripts/setup.sh` (the underlying implementation).
- `perl` and `python3` (used by `_strip_bashrc_snippet`).
